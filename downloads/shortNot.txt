***Calculation***

1. (*,/) multiply and dividing thamai ekatama wenne.

2. (+,-) additional and subtraction thamai dewaniyata wenne.

3. (*,/) me dekata eka para calculation ekaka thibunoth laft to right thamai calculation eka wenne.

4. (+,-) me dekata eka para calculation ekaka thibunoth laft to right thamai calculation eka wenne.

1.Math.round((2095 + 789) * 0.1) // meka use karala dashama sankya 2i display wenne.
2.Math.ceil(3.1) // answer eka 4 (4 => 3.1)
3.Math.floor(2.8) // answer eka 2 (2 =< 2.8)

***Concatenation***

String ekak liyanna puluwan akara 3k thiyanawa.

1. 'Hello'
2. "Hello" 
3. `Hello` (String Interpolation / Template Literals) (multiline text liyannath meka use karanawa)

examples:

(1 / 2) 'Total cost: $' + (599 + 295) / 100
(3) `Total cost: $${(599 + 295) / 100}`
